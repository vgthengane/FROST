# Point-cloud FSCIL session indexes

Vendored FSCIL-3D / microshape `index_files` (class IDs + per-session sample lists).
Used by `datasets/fscil3d_index.py` for all PC protocols. No `third_party/microshape`
clone required for training.

Also includes `shapenet_co3d_info.py` (SN→CO3D task schedule).

Image session lists live in `../session_images/`.

Source: [FSCIL-3D](https://github.com/townim-faisal/FSCIL-3D).
